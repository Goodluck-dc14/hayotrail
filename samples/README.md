# Sample bills

These are **fictional** bill documents made for this student project. No real patients, clinics or insurers.

Only the SHA-256 hash of each file goes on the blockchain. `bill-001-consultation-TAMPERED.txt` is a copy of bill 001 with the amount changed from 15000 to 18000, to show that any change gives a completely different hash.

Run `node scripts/hashBill.js samples/<file>` to see a file's hash.
